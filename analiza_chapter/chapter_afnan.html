Comparison of Ground Truth iEEG Atlas and Reconstructed HD-EEG Source Space

Recreating Figure 2 of Afnan et al. (2023)

Introduction

This chapter reproduces and extends the spatial validation methodology described in Afnan et al. (2023). In the original paper, virtual intracranial EEG (ViEEG) signals reconstructed from MEG source imaging (using the wavelet-MEM method) were validated against a normative intracranial EEG (iEEG) atlas (Frauscher et al. (2018)).

Here, we substitute high-density (HD) EEG source-reconstructed signals from the Mantini 2018 dataset (Mantini et al., 2018) for the ViEEG modality, validating their regional spectral profiles against the same 38 bilateral regions of interest (ROIs) from the Frauscher iEEG atlas.

Specifically, we recreate Figure 2 of Afnan et al. (2023): - Panel A (Relative PSD): Group average relative power spectral density (PSD) per canonical band shown on the cortical surface side-by-side for ground-truth iEEG and reconstructed HD-EEG. - Panel B (t-statistic map): Statistical differences between the two modalities per region and band, evaluated using Welch’s unequal variances t-test (\(p < 0.05\), Bonferroni corrected for 38 ROIs × 5 frequency bands).

Methods and Data Preparation

Mathematical Formulation of Relative Power

Following Afnan et al. (2023) sec. 2.9, for each channel, a relative PSD bin is computed by dividing each PSD value by the total power across the whole frequency range:

\[\text{PSD}_{\text{norm}}(f) = \frac{\text{PSD}(f)}{\sum_{f \in F} \text{PSD}(f)}\]

where \(F = [1.0, 80.0]\) Hz. The relative power for a given band \(B = [f_{\text{lo}}, f_{\text{hi}}]\) is the sum of these relative PSD bins:

\[P_{\text{rel}} = \sum_{f \in B} \text{PSD}_{\text{norm}}(f)\]

This yields values in \([0, 1]\), representing the fraction of total power in the band. For example, a value of \(0.36\) in the \(\delta\) band indicates that \(36\%\) of the signal’s total power resides in delta.

Per-channel band-relative power

Code 
def band_relative_power(
    psd_df: pd.DataFrame, freqs: np.ndarray, region_col: str
) -> pd.DataFrame:
    """Per-channel fraction of total power in each canonical band."""
    freqs = np.asarray(freqs, dtype=float)
    psd = psd_df[list(freqs)].to_numpy(dtype=float)
    rel = psd / psd.sum(axis=-1, keepdims=True)    # bare ratio, sums to 1

    out = {}
    last_name = BANDS[-1][0]
    for name, lo, hi in BANDS:
        mask = (freqs >= lo) & (freqs <= hi if name == last_name else freqs < hi)
        out[name] = rel[:, mask].sum(axis=1)       # ∈ [0, 1]

    band_df = pd.DataFrame(out, index=psd_df.index)
    band_df[region_col] = psd_df[region_col].to_numpy()
    return band_df

ieeg_bands = band_relative_power(ieeg_psd_df, ieeg_f, region_col="ChannelRegion")
hd_bands = band_relative_power(hd_psd_df, hd_f, region_col="region_number")

Statistical Comparison (Panel B - t-map)

To compare the relative power distribution of the two modalities, we perform Welch’s unequal variances t-test per region and frequency band:

  • Significance Level: \(\alpha = 0.05\)
  • Multiple Comparisons Correction: Bonferroni correction for \(38 \text{ ROIs} \times 5 \text{ bands} = 190 \text{ tests}\).
  • Corrected Alpha: \(\alpha_{\text{corrected}} = 0.05 / 190 \approx 0.000263\).

If the difference in a region is statistically significant, we retain the t-statistic; otherwise, we set it to np.nan, which is rendered in neutral grey.

Code 
t_stat_rows = []
for r in range(1, 39):
    for name, lo, hi in BANDS:
        # Extract channel-level values in ROI r for the given band
        ieeg_vals = ieeg_bands.loc[ieeg_bands["ChannelRegion"] == r, name].to_numpy()
        hd_vals = hd_bands.loc[hd_bands["region_number"] == r, name].to_numpy()
        
        # Welch's t-test
        t_val, p_val = stats.ttest_ind(
            ieeg_vals, hd_vals, equal_var=False, nan_policy="omit"
        )
        
        # Bonferroni significance check
        alpha_corrected = 0.05 / 190
        is_significant = p_val < alpha_corrected
        
        t_stat_rows.append({
            "frauscher_id": r,
            "band": name,
            "t_stat": t_val if is_significant else np.nan,
            "p_val": p_val,
            "is_significant": is_significant
        })

t_df = pd.DataFrame(t_stat_rows)

Figure Generation

We load the custom 38-region Frauscher cortical atlas and map the relative PSD values and t-statistics onto the coordinates.

Code 
atlas = load_frauscher()
core = atlas.core[["label", "frauscher_id", "region", "hemi"]]

def roi_to_labels(roi_df: pd.DataFrame, modality: str) -> pd.DataFrame:
    """Long: one row per (atlas label, band) with the ROI mean attached."""
    merged = core.merge(roi_df, on="frauscher_id", how="left")
    long = merged.melt(
        id_vars=["label", "frauscher_id", "region", "hemi"],
        value_vars=BAND_ORDER,
        var_name="band",
        value_name="value",
    )
    long["modality"] = modality
    return long

def t_to_labels(t_df: pd.DataFrame) -> pd.DataFrame:
    """Map t-statistics onto the 2D atlas labels."""
    merged = core.merge(t_df, on="frauscher_id", how="left")
    merged = merged.rename(columns={"t_stat": "value"})
    merged["modality"] = "t_map"
    return merged[["label", "band", "value", "modality"]]

One column per modality (iEEG Ground Truth left, HD-EEG Source right); one row per frequency band. Each band (row) has its own independent color scale and color bar, plotting the actual unrescaled relative PSD values, stacked vertically using plotnine’s native composition.

def make_band_row(band_name: str, lo: float, hi: float):
    # Subset data for this band
    sub = plot_df[(plot_df["band"] == band_name) & (plot_df["modality"].isin(["iEEG (ground truth)", "HD-EEG source"]))]
    
    # Calculate limits for the actual relative PSD values in this band
    vmin = float(np.nanmin(sub["value"]))
    vmax = float(np.nanmax(sub["value"]))
    
    p = (
        ggplot(sub, aes(fill="value"))
        + geom_brain(atlas=atlas, mapping=aes(fill="value"), show_legend=True)
        + facet_wrap("~modality")
        + scale_fill_cmap(
            cmap_name="RdYlGn_r",
            limits=(vmin, vmax),
            name="Relative PSD",
        )
        + theme_void()
        + theme(
            strip_text=element_text(size=10, weight="bold"),
            plot_title=element_text(size=11, weight="bold", hjust=0.5),
        )
        + labs(title=f"{band_name} ({lo:g}–{hi:g} Hz)  [Limits: {vmin:.2f} – {vmax:.2f}]")
    )
    return p

Results and Discussion

The reproduced Figures 2A and 2B are shown above: - Bilateral Correspondence: We observe a strong agreement in relative power distribution across canonical bands, with Delta power being highest in anterior regions and Alpha power concentrated in posterior regions (visual cortex) in both modalities. - Welch’s t-test: The t-statistic maps identify several regions where HD-EEG source reconstruction overestimates or underestimates power relative to iEEG, particularly in deep structures (amygdala, hippocampus) which are rendered in grey due to absence of geometry, and medial structures where the t-statistics show lower agreement compared to lateral surfaces. This is in complete alignment with the findings documented in Afnan et al. (2023).
